# Temporal Food Waste Pattern Analytics

CSL7360 Computer Vision project, IIT Jodhpur.

A camera-based system that measures leftover food **per dish on each canteen plate**, attaches the
**time context** (date, weekday, meal, minutes into service), finds **recurring waste patterns**,
and turns them into **menu and quantity recommendations**.

Pipeline: before + after photo → tray/plate detection → colour normalisation → SIFT + RANSAC
alignment → food segmentation (classical baseline or YOLOv8n-seg) → waste % per dish →
4-week event log → TWCI + pattern classes → forecast + recommendations.

> **Data.** Only the PUBLIC canteen dataset is used: Roboflow "PROJ3 - Food waste detection"
> (Piccoli et al. 2025, *Applied Sciences* 15(13):7137, CC BY 4.0) - 175 real photos of plates at the
> start, middle and end of meals, instance-segmented. `tools/import_public.py` groups its 87 classes into
> 15 dishes (rice, pasta, potato, vegetables, salad, beans, soup, bread, fruit, dessert, cheese, eggs,
> chicken, meat, fish): 142 photos with food become the before photos, the 33 finished plates become
> negatives for the leftover model. After photos are generated by removing a known share of each
> dish, and a 4-week canteen log (breakfast / lunch / dinner) with **planted patterns** is simulated,
> so pattern recovery can be measured against an answer key. Menu rule: non-veg (chicken, meat, fish,
> eggs) and cheese only at dinner.

## Folder layout
```
src/
  common.py             label I/O, masks, name cleaning (shared)
  preprocess.py         B1  plate/tray detection, rectification, denoise, glare, white balance, CLAHE
  simulate_timeline.py  B2  4-week log with planted patterns -> events.csv, answer_key.csv
  generate_after.py     B2  synthetic "eating": after images + leftover labels
  align.py              B3  SIFT + ratio test + RANSAC homography (ECC / plate fallbacks)
  segment.py            B4  classical baseline (Lab + GrabCut + k-means + LBP) and YOLOv8n-seg
  waste.py              B5  waste % per dish, MAE, ablation
  analytics.py          B6  TWCI, pattern classes, serving-time decay, pairing, forecast, recovery
app.py                  B7  Streamlit demo
collect_results.py      B8  gathers all numbers + figures into results/report/
tools/import_public.py        public canteen export -> dataset/ (15 dish groups, plates, empty plates)
notebooks/train_yolo.ipynb    YOLO training on a Kaggle / Colab GPU
dataset/                before/ labels/ plates/ empty/ classes.txt menu.csv patterns.yaml generated/
models/best.pt          trained YOLOv8n-seg weights (dish model, before photo)
models/food_best.pt     one-class leftover model (after photo)
results/                all outputs; results/report/ = summary for the report
```

## Setup
```
pip install -r requirements.txt
```
Run every command from the project root (the folder that contains `src/`).

## Run the full pipeline
```
# 1. dataset from the public export (+ menu.csv and patterns.yaml in dataset/)
python tools/import_public.py "PATH/TO/PROJ3 - Food waste detection" --out dataset

# 2. 4-week log + synthetic after images
python src/simulate_timeline.py --dataset dataset
python src/generate_after.py   --dataset dataset

# 3. segmentation sets (split BY PHOTO, 15 % held out) -> train both on Kaggle with notebooks/train_yolo.ipynb
python src/segment.py prepare      --dataset dataset                 # -> yolo_ds.zip  -> models/best.pt
python src/segment.py prepare_food --yolo-ds yolo_ds --dataset dataset   # -> food_ds.zip -> models/food_best.pt
python src/segment.py evaluate --dataset dataset --weights models/best.pt

# 4. waste: held-out photos (fair accuracy), ablation, then all plates
python src/waste.py --dataset dataset --seg yolo --weights models/food_best.pt --ablation --split yolo_ds/split.json --out results/yolo_ablation
python src/waste.py --dataset dataset --seg classical --split yolo_ds/split.json --out results/classical
python src/waste.py --dataset dataset --seg yolo --weights models/food_best.pt --out results/waste_all_yolo

# 5. temporal analytics: true waste (upper bound) and measured waste (end-to-end)
python src/analytics.py --dataset dataset --out results/analytics --metrics results/analytics/metrics.json
python src/analytics.py --dataset dataset --out results/analytics --robustness
python src/analytics.py --dataset dataset --pred results/waste_all_yolo/waste_predictions.csv \
                        --out results/analytics_measured --metrics results/analytics_measured/metrics.json

# 6. alignment check + collect everything
python src/align.py --dataset dataset --limit 40 --out results/align
python collect_results.py                                   # -> results/report/RESULTS.md + figures/
```

## Demo
```
streamlit run app.py
```
Sidebar: dataset folder `dataset`, analytics folder `results/analytics_measured`, dish model `models/best.pt`, leftover model `models/food_best.pt`.
Tab 1 measures one plate (pick a generated event, or upload a before + after photo of the
**same** tray). Tabs 2–4 show heatmaps, detected patterns and recommendations.

## Course topics used
Filtering and restoration (bilateral, median, inpainting) · colour constancy and CLAHE ·
Hough circles, ellipse fitting, homography and warping · SIFT, RANSAC, ECC · k-means, GrabCut
(graph cut), LBP texture · CNN instance segmentation (YOLOv8-seg).
